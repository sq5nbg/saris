# SARIS : System Archiwizacji Raportów I Sprawozdań
- Report Archiving System

## About
The SARIS software is used to receive and store reports in the student laboratory.
This is an application written in Rust using the Axum framework.
The application was made using Claude Code with the Opus 5.5 model, according to the claude.md file.

## Requirements
- Rust development environment

## Compilation
Typical rust commands in repository:
```bash
cargo build
cargo run
```
